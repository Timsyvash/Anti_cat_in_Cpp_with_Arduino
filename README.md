# 🚨 Автоматичний світло-звуковий відлякувач на Arduino (з RGB Common Anode)

Проєкт автономного світло-звукового відлякувача (або тривожної сигналізації) на базі мікроконтролера **Arduino**, інфрачервоного датчика руху **PIR**, **RGB-світлодіода зі спільним анодом** та **п'єзодинаміка (Buzzer)**.

Пристрій автоматично виявляє рух у зоні дії датчика та вмикає серію із 7 якравих стробоскопічних спалахів випадковими кольорами, супроводжуючи кожен спалах високим звуковим сигналом.

---

## 🚀 Основні можливості

- 👁️ **Безконтактна детекція:** Спрацювання від PIR-датчика руху.
- 🌈 **Стробоскоп з випадковими кольорами:** RGB-світлодіод змінює відтінок при кожному спалаху.
- ⚡ **Підтримка спільного анода (Common Anode):** Код інвертовано для правильної роботи зі світлодіодами, у яких спільний плюс (+5V).
- 🔊 **Звуковий сигнал тривоги:** 4 кГц п'єзо-сигнал синхронізований зі спалахами.
- ⏱️ **Захист від частих хибних спрацювань:** Налаштований затримка-таймаут між серіями тривог.

---

## 🛠️ Необхідні компоненти

- **Мікроконтролер:** Arduino (Nano / Uno / Pro Mini / Mega)
- **Датчик руху:** PIR HC-SR501 (або AM312)
- **Світлодіод:** RGB-світлодіод зі **спільним анодом** (4 виводи)
- **Зумер:** Пасивний або активний п'єзодинамік (Buzzer)
- **Резистори:** 3 × 220 Ом (для каналів R, G, B світлодіода)
- **Джерело живлення:** 5V (USB або зовнішній блок живлення)
- **Допоміжні деталі:** Сполучні дроти (Dupont), макетна плата (Breadboard)

---

## 🔌 Схема підключення (Pinout)

> ⚠️ **Зверніть увагу:** Найдовший вивід RGB-світлодіода зі спільним анодом підключається до **+5V**, а інші 3 ніжки — через резистори 220 Ом до цифрових ШІМ-пінів Arduino.

| Компонент | Пін компонента | Пін Arduino | Примітка |
| :--- | :--- | :--- | :--- |
| **PIR Sensor** | VCC | **5V** | Живлення датчика |
| | GND | **GND** | Спільне заземлення |
| | OUT (Signal) | **Pin 8** | Цифровий вхід руху |
| **Buzzer** | (+) / Signal | **Pin 4** | Звуковий вихід |
| | (-) / GND | **GND** | Спільне заземлення |
| **RGB LED (Common Anode)**| **Анод (Найдовша ніжка)**| **+5V** | **Живлення +5V (Спільний плюс)** |
| | Red (Катод R) | **Pin 7** (PWM) | Через резистор 220 Ом |
| | Green (Катод G) | **Pin 6** (PWM) | Через резистор 220 Ом |
| | Blue (Катод B) | **Pin 5** (PWM) | Через резистор 220 Ом |

---

## 💡 Логіка керування спільним анодом

Оскільки анод підключений до **+5V**, керування здійснюється низьким рівнем на виходах Arduino:
- `analogWrite(PIN, 255)` — Світлодіод **ВИМКНЕНО** (різниця потенціалів 0V).
- `analogWrite(PIN, 0)` — Світлодіод горить на **максимальну яскравість** (різниця потенціалів 5V).
- Для довільної яскравості використовується вираз: `255 - brightness`.
